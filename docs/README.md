# 同城预约上门服务系统

## 项目简介

同城预约上门服务系统是一个综合性的本地生活服务平台，支持上门服务和门店核销两种服务模式，涵盖自营和多商家联营两种运营方式。系统包含PHP管理后台、API接口层、以及用户端、技师端、商家端三个微信小程序。

## 功能特性

### 核心业务模式
- **自营模式**：平台直接管理技师和订单，支持派单和抢单
- **多商家联营**：支持多个商家入驻，每个商家独立管理门店、技师和订单
- **多城市支持**：支持多城市运营，每个城市可配置专属服务项目
- **服务方式**：上门服务 + 到店核销

### 下单方式
- 选择服务项目下单
- 选择服务人员下单
- 选择门店下单

## 快速开始

### 环境要求
- PHP >= 7.4
- MySQL >= 5.7
- Nginx/Apache
- 微信小程序开发工具
- PHP扩展：mysqli、pdo_mysql、json、mbstring、curl

### 部署步骤

1. **导入数据库**
   ```bash
   mysql -u root -p tongcheng < database/tongcheng.sql
   ```

2. **配置管理后台**
   - 修改 `admin/config/database.php` 数据库配置
   - 修改 `admin/config/config.php` 系统配置

3. **配置API接口**
   - 修改 `api/config/database.php` 数据库配置
   - 修改 `api/config/config.php` 系统配置（微信支付、JWT密钥等）

4. **配置小程序**
   - 在微信公众平台注册小程序并获取AppID
   - 修改各端小程序 `project.config.json` 中的appid
   - 修改各端小程序 `app.js` 中的baseUrl为你的API地址

5. **配置Web服务器**
   - 配置虚拟主机指向项目根目录
   - 确保URL重写已启用

## 开发规范

### 代码规范
- PHP遵循 PSR-4 自动加载规范
- 数据库操作使用预处理语句，防止SQL注入
- 接口返回统一格式：`{code: 0, msg: 'success', data: {...}}`
- 小程序使用ES6语法，遵循微信小程序开发规范

### 安全规范
- 所有用户输入进行过滤和验证
- 敏感数据加密存储
- API接口使用JWT认证
- 开启CORS安全配置
- 上传文件进行类型和大小验证

## 常见问题

### 1. 小程序无法连接API
- 检查API地址配置是否正确
- 检查服务器是否开启CORS
- 检查小程序后台是否配置了合法域名

### 2. 微信登录失败
- 检查微信小程序AppID和AppSecret配置
- 检查服务器是否能正常访问微信接口

### 3. 支付功能无法使用
- 检查微信支付商户号配置
- 检查支付证书是否正确上传
- 检查支付回调地址是否可访问
